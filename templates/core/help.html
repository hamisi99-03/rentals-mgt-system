Month-end routine

A calm checklist for the last working day of the month.

  1. Record every payment received and import the M-Pesa/bank statement; confirm each match.
  2. Enter meter readings for water, electricity and other utilities.
  3. Open Billing and generate the month's invoices. Check the skipped count and any rent-increase notes.
  4. Print or save the invoices and receipts you need.
  5. Review the Dashboard: rent due, arrears, overdue tenants and open maintenance.
  6. Check Reports for arrears, income and expenses, and the tax summary.
  7. Run a manual backup and confirm it appears in the backup history.

If the app will not start

Open the data folder, keep a copy of the latest backup, then export a support bundle. The log file in the data folder has the full technical detail; the app itself only shows plain-language messages.
