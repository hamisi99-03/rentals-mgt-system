Restore

Restoring is deliberately a command-line action so it cannot be triggered by accident.

Run this on the PC with the app closed:

python manage.py restore_backup "PATH\\TO\\rentals-YYYYMMDD-HHMMSS.sqlite3" --yes

The command validates the file, takes a safety backup first, then copies it into place and writes an audit entry.
